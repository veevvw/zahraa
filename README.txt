# Birthday Surprise Website

موقع تهنئة تفاعلي مستوحى من الفيديو: شاشة Matrix، ظهور الاسم، كعكة متحركة، رسالة شخصية، ومعرض صور.

## التشغيل
افتح `index.html` بالمتصفح. يحتاج اتصال إنترنت لتحميل خط Cairo من Google Fonts، ويمكن تشغيله بدونه أيضاً.

## تخصيص الموقع
افتح `script.js` وعدّل كائن CONFIG:
- name: اسم صاحبة عيد الميلاد (يفضل أحرف إنجليزية قصيرة أو اسم عربي)
- sender: اسم المرسل
- message: نص الرسالة

## إضافة الصور
ضع صورك داخل مجلد `photos` وسمّها بالضبط:
photo1.jpg إلى photo7.jpg
يمكنك استبدالها بصور JPG أو تعديل الامتدادات في index.html.

## النشر مجاناً
ارفع محتويات المجلد إلى GitHub ثم فعّل GitHub Pages من Settings > Pages، أو اسحب المجلد إلى Netlify Drop.
